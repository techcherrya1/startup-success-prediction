# Startup Success Prediction

A machine learning project that predicts whether a startup is likely to succeed, based on funding, team, and company-level features.

## What it does
- Processed a large-scale dataset of 100,000+ records — cleaning noisy data and encoding features to surface behavioral patterns.
- Trained and compared three classifiers: Logistic Regression, Decision Tree, and Random Forest.
- Best model achieved up to 73.4% accuracy and 72.9% F1 score.

## Why I built it
Wanted practice extracting actionable signal from high-volume, high-noise data — a workflow that transfers directly to telemetry and trace-data analysis, not just business prediction problems.

## Tech stack
Python · Pandas · NumPy · Scikit-learn

## How to run
```bash
pip install -r requirements.txt
python train.py
```
